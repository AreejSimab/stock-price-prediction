# Data

The dataset is **not** included in this repository.

1. Download **Apple Stock Price History** from Kaggle:
   https://www.kaggle.com/datasets/shamimhasan8/apple-stock-price-history-dataset
2. Save the file as `Apple_stock_data.csv` in this folder, so the path is `data/Apple_stock_data.csv`.

The file has one row per trading day (12 Dec 1980 to 9 Sep 2025) with the columns
`Date, Open, High, Low, Close, Volume`. Prices are adjusted for stock splits.
